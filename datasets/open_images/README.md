# Open Images adapter data

SceneGrammarKit uses official Open Images V7 metadata from Google and image pixels
from the official CVDF Open Images S3 storage. The repository contains only the
small frozen case record and documentation here. Bulk metadata, candidate
downloads, and local caches are intentionally ignored.

The reproducible reproducibility inputs are stored in `inputs/real_cases/`.

Official resources:

- `https://storage.googleapis.com/openimages/web/download_v7.html`
- `https://storage.googleapis.com/openimages/web/factsfigures_v7.html`
- `https://github.com/cvdfoundation/open-images-dataset`
- `https://open-images-dataset.s3.amazonaws.com/validation/<image-id>.jpg`
