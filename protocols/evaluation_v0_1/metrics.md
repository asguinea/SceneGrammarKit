# Evaluation metrics

The controlled set contains twelve fixed definitions: four urban streets, four
repeated facades, and four indoor corridors. For each case the evaluator reports
validation and execution success, source-observation coverage, normalized split
boundary error, repeat decisions, symbolic node counts, canonical byte counts,
flat-baseline equivalence, and whether a predefined edit is valid and visibly
changes the render.

The three attributed Open Images examples are reported descriptively. They are
not aggregated into an accuracy estimate. Runtime measurements are diagnostic
and excluded from canonical hashes and cross-case claims.
